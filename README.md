# CS 499 Computer Science Capstone ePortfolio

This repository contains my final ePortfolio for the CS 499 Computer Science Capstone at Southern New Hampshire University. The portfolio demonstrates the skills and knowledge I developed throughout the Bachelor of Science in Computer Science program.

## Capstone Project

For my capstone project, I enhanced a Weight Tracking Android application that I originally developed in CS 360 Mobile Architecture and Programming. The application was developed using Java, Android Studio, XML, and SQLite.

The original application was enhanced in the three main areas of the CS 499 capstone:

- Software Design and Engineering
- Algorithms and Data Structures
- Databases

The enhancements focused on improving code organization, input validation, usability, data processing, database design, data integrity, performance, and security.
