Professional Self-Assessment

Completing the Computer Science program has helped me develop a stronger understanding of how software is designed, developed, tested, and improved. Throughout the program, I gained experience with programming, software engineering, databases, algorithms, data structures, security, web development, and mobile applications. Earlier in my coursework, I was often focused mainly on making sure a program worked correctly. As I progressed, I learned to consider other important factors such as code organization, efficiency, usability, security, and maintainability. Developing this ePortfolio allowed me to look back at earlier work and see how my approach to solving computer science problems has improved.

My coursework also helped shape my professional goals. I am interested in pursuing opportunities in software development or data-related fields because I enjoy building applications and using data to solve problems. Throughout the program, I worked with technologies such as Java, Python, SQL, SQLite, HTML, CSS, JavaScript, and Android Studio. My web development coursework gave me experience creating organized, user-friendly websites, while other courses gave me experience working with databases and analyzing and presenting data. Learning different technologies has made me more comfortable adapting to new tools instead of depending on one programming language or development environment.

Another important part of my development has been learning how collaboration and communication affect the success of a technical project. Through discussions, project requirements, peer interactions, and instructor feedback, I learned to consider perspectives beyond my own. Collaboration involves listening to feedback, explaining decisions, considering user and stakeholder needs, and being willing to change an approach when another solution provides better results. The feedback I received throughout this capstone reinforced this idea by showing me that improving existing code can sometimes provide more value than adding unnecessary features. This is an important lesson for professional development environments where changes should support the goals of a project rather than simply increase its complexity.

My coursework also required me to communicate technical information through written assignments, documentation, presentations, discussions, and project work. These experiences taught me that technical knowledge needs to be communicated differently depending on the audience. The code review for this capstone is one example because I had to explain the existing application, identify problems, and describe my planned improvements in a way that could be understood without focusing only on source code. This experience helped prepare me to communicate with developers, managers, users, and other stakeholders who may have different levels of technical knowledge.

My understanding of data structures and algorithms also grew throughout the program. I learned that solving a problem involves more than producing the correct result. The way data is stored and processed affects the efficiency and maintainability of a solution. Working with arrays, lists, collections, and algorithms taught me to consider how information will be accessed and modified before choosing an approach. I also became more aware of trade-offs between efficiency, simplicity, and maintainability. These skills have strengthened my ability to break larger problems into smaller steps and evaluate different solutions before implementing them.

Software engineering and database development have been other important areas of my education. Through software development projects, I gained experience with object-oriented programming, modular design, user interfaces, testing, debugging, validation, and documentation. I learned that software should not only function correctly but should also be understandable and maintainable. Database coursework gave me experience with SQL, relational databases, CRUD operations, relationships, keys, data types, constraints, and queries. These experiences helped me understand how application code and databases work together and how decisions in one part of a system can affect the rest of the application.

Security has also become an important part of how I approach development. I learned that security should be considered during the design process rather than added after an application is finished. Input validation, access control, data integrity, and defensive programming can reduce vulnerabilities and protect information. I now try to consider not only what an application should do when used correctly, but also what could happen when it receives unexpected input or when someone attempts to access information they should not be able to use. This security mindset is something I plan to continue developing throughout my career.

The artifact included in this ePortfolio brings these skills together. I selected a Weight Tracking Android application that I originally developed in CS 360 Mobile Architecture and Programming. Using the same application for all three enhancement categories provides a clear comparison between my earlier work and the skills I have developed since creating the original project.

The first enhancement focuses on software design and engineering. I refactored larger sections of code into smaller methods, strengthened input validation, improved communication between application components, made better use of Android resources, and improved the weight entry process. These changes made the application easier to understand and maintain while demonstrating that improving existing code can be just as valuable as adding new functionality.

The second enhancement focuses on algorithms and data structures. Weight entries are stored in an ArrayList and sorted by date so users can easily locate recent information. I also added calculations for current, highest, lowest, and average weight along with total weight change. These calculations process the stored information efficiently and demonstrate how algorithms and appropriate data structures can make existing data more useful to the user.

The third enhancement focuses on databases. I redesigned parts of the SQLite database so weight entries are connected to individual users through a user ID. I also improved data types, constraints, queries, CRUD operations, and indexing. User-specific database operations help ensure that accounts access only their own weight information. These changes improved data organization, integrity, performance, and privacy while creating a database structure that is more appropriate for a multi-user application.

Together, the original application and the three enhancements demonstrate my growth across the Computer Science program. They show how software engineering, algorithms, data structures, databases, security, communication, and user needs work together when creating a complete computing solution. The progression from the original application to the enhanced version also demonstrates my ability to evaluate existing work, identify areas for improvement, and make changes that have a clear purpose.

Completing this capstone and ePortfolio has helped prepare me to enter the computer science field with a stronger technical foundation and a better understanding of professional development practices. I have become a more thoughtful problem solver who considers whether a solution is organized, efficient, maintainable, secure, and useful instead of only asking whether it works. I also understand that computer science requires continuous learning as technologies and industry practices change. The skills represented in this portfolio provide a foundation that I can continue building on as I pursue opportunities in software development and data-related fields.

Enhancement One: Software Design and Engineering

The first enhancement focused on improving the overall structure, maintainability, usability, and reliability of the Weight Tracking application.

Key Improvements

  • Refactored large sections of code into smaller and more focused methods
  • Added stronger username and password validation
  • Improved weight entry validation
  • Added a date picker for consistent date entry
  • Reduced coupling between the RecyclerView adapter and database layer
  • Moved hardcoded interface text into Android string resources
  • Improved defensive programming and application reliability

These changes demonstrate my growth in object-oriented programming, application architecture, user interface design, validation, and maintainable software development.

Enhancement Two: Algorithms and Data Structures

The second enhancement focused on improving how the application organizes and processes stored weight information.

Key Improvements

  • Used an ArrayList to manage weight entries in memory
  • Sorted weight entries by date using Collections.sort and a comparator
  • Displayed the newest weight entries first
  • Calculated current, highest, lowest, and average weight
  • Calculated total weight change
  • Performed multiple statistical calculations in a single pass through the list
  • Changed weight values from strings to numerical double values

These improvements demonstrate my ability to select appropriate data structures, implement algorithms, and consider efficiency when designing computing solutions.

Enhancement Three: Databases

The third enhancement focused on improving the SQLite database structure, data integrity, user privacy, and database performance.

Key Improvements

  • Connected weight entries to individual user accounts using a user ID
  • Created a one-to-many relationship between users and weight records
  • Added foreign key support
  • Changed weight values to the SQLite REAL data type
  • Added database constraints to improve data integrity
  • Prevented duplicate weight entries for the same user and date
  • Updated CRUD operations to use the logged-in user's ID
  • Added an index to improve weight history queries
  • Improved separation and privacy of user information

These improvements demonstrate my knowledge of relational database design, SQL operations, data integrity, performance, access control, and secure application development.
